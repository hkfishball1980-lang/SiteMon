# 地盤巡查 Site Inspection v3.0 (Project → Structural Elements → HD Appendix X Report)

專為一日巡查一條屋邨、記錄多個 Structural Elements 並生成完整結構巡查報告設計的離線 iPad PWA。

## v3.0 架構亮點
1. **屋邨專案（Project）層級**：開一個 Project 填一次 DMO、Estate、Inspection Date、Handover Date 及 SE / SSE 資料。
2. **多項構建物（Structural Elements）**：於同一個屋邨專案內不斷新增不同構建物（Canopy、Retaining Wall、Staircase、Columns 等），每項構建物獨立擁有完整 HD Appendix X 1.1–4.3 評級、5.1 Remarks、GPS 坐標及獨立巡查相片與備註。
3. **整份屋邨巡查報告（Full Inspection Report PDF）**：一鍵生成包含「屋邨摘要總表」＋「每個 Structural Element 獨立一頁 Appendix X 報告及相片」的完整 PDF／列印版。
4. **專案 ZIP 匯出與還原**：支援按單一專案或全部專案匯出 Excel、CSV、JSON 備份及按構建物分類的相片。
